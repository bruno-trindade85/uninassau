# Template Mestre de Aula Interativa

Pasta permanente para guardar o modelo-base das aulas interativas da UNINASSAU.

Arquivo principal: `template_mestre_aula_interativa.html`.

Use este arquivo como base para novas aulas, fazendo uma cópia para a pasta do período e da disciplina. Não altere o mestre com conteúdo específico de uma aula. Substitua os campos `[[ ... ]]` e preserve a estrutura visual, responsiva e interativa.
