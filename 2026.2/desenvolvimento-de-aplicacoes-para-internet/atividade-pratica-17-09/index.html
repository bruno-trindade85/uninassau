Página Web com HTML, CSS e JavaScript

Desenvolva uma aplicação simples aplicando os conteúdos já trabalhados em sala. Escolha uma das 10 regras de negócio e implemente a solução no navegador.

Importante: nesta atividade não serão utilizados Node.js, API, Express ou banco de dados. O foco é praticar HTML, CSS, JavaScript, variáveis, funções, condicionais, objetos/arrays e interação básica com a página.

Objetivo

HTML

Criar a estrutura da página com títulos, campos, botões e área de resultado.

CSS

Organizar visualmente a aplicação com cores, espaçamento, alinhamento e legibilidade.

JavaScript

Capturar dados, executar a regra de negócio e mostrar o resultado ao usuário.

Lógica

Utilizar funções, variáveis e decisões com if/else quando necessário.

Requisitos obrigatórios

  1. Criar uma pasta para o projeto.
  2. Utilizar arquivos separados: index.html, style.css e script.js.
  3. Criar uma interface com os campos necessários para a regra escolhida.
  4. Utilizar pelo menos uma função JavaScript criada pelo aluno.
  5. Utilizar variáveis para armazenar os dados informados.
  6. Utilizar if/else quando a regra escolhida exigir tomada de decisão.
  7. Exibir o resultado da operação na própria página.
  8. Validar campos vazios ou valores inválidos.
  9. Utilizar objeto ou array quando fizer sentido para organizar os dados.
  10. Testar a aplicação no navegador antes da entrega.

Escolha uma regra de negócio

#RegraO que a aplicação deverá fazer
1Desconto em produtoReceber o preço e aplicar 10% de desconto quando o valor for maior que R$ 100.
2Situação do alunoReceber duas notas, calcular a média e informar Aprovado ou Reprovado.
3Frete grátisReceber o valor da compra e informar se o cliente possui frete grátis a partir de R$ 200.
4Classificação por idadeReceber a idade e classificar a pessoa por faixa etária.
5Controle de estoqueReceber estoque disponível e quantidade desejada e informar se a compra pode ser realizada.
6Desconto por quantidadeCalcular o total da compra e aplicar desconto quando forem compradas 5 ou mais unidades.
7Login simplesComparar usuário e senha informados com valores previamente definidos e informar se o acesso foi permitido.
8Conversor de temperaturaReceber uma temperatura em Celsius e converter para Fahrenheit.
9Cálculo de IMCReceber peso e altura, calcular o IMC e apresentar uma classificação simples.
10Orçamento de serviçoReceber quantidade de horas e valor por hora, calcular o total e aplicar desconto conforme a regra definida.

Estrutura esperada

atividade-web/
├── index.html
├── style.css
└── script.js

Entrega

Entregar a pasta do projeto contendo os três arquivos. O código deverá funcionar ao abrir o index.html no navegador.
