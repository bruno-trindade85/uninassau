Análise de 3 Repositórios no GitHub

Você deverá escolher três repositórios públicos diferentes no GitHub, observar as informações disponíveis em cada projeto e registrar sua análise usando suas próprias palavras.

Coding I Unidade 3 repositórios públicos Entrega pelo Google Forms

Objetivo

Compreender como projetos reais são organizados no GitHub e identificar elementos importantes de um repositório, como README, commits, contribuidores, Issues e linguagem predominante.

Importante

A atividade é individual. As respostas devem ser escritas com suas próprias palavras e baseadas no que você observar diretamente nos repositórios escolhidos.

Antes de começar: abra o Modelo de Entrega, faça uma cópia para sua conta e preencha somente os campos indicados no documento.

O que analisar em cada repositório

1. IdentificaçãoNome e link do repositório.
2. FinalidadeExplique para que serve o projeto e qual necessidade ele atende.
3. ProprietárioIdentifique se é mantido por uma pessoa, organização ou empresa.
4. LinguagemInforme a linguagem de programação predominante.
5. CommitsRegistre a quantidade de commits no momento da consulta.
6. ContribuidoresInforme a quantidade ou os principais contribuidores visíveis.
7. READMEExplique a função do arquivo e destaque duas informações importantes.
8. IssuesEscolha uma Issue aberta e explique o que está sendo discutido.
9. Um commitRegistre mensagem, autor, data e o que aparentemente foi alterado.

Como realizar a atividade

1

Escolha três repositórios

Selecione três repositórios públicos diferentes no GitHub.

2

Faça a análise

Observe os nove itens indicados acima em cada um dos três repositórios.

3

Preencha o modelo

Faça uma cópia do documento modelo e complete todos os campos marcados para preenchimento.

4

Envie pelo formulário

Ao finalizar, utilize o formulário disponível no final desta mesma página para realizar a entrega.
