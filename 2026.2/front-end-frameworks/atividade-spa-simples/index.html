Construção de uma SPA Simples

Você receberá uma aplicação pronta em um único arquivo HTML. A partir dela, deverá escolher um estudo de caso, adaptar o sistema e depois organizar o código em arquivos separados.

SPADOMEventosJavaScriptOrganização de arquivos

Objetivo

Praticar a construção de uma SPA simples, manipular o DOM com JavaScript, trabalhar com eventos e compreender a separação entre estrutura HTML, apresentação CSS e comportamento JavaScript.

Importante

Não será utilizado banco de dados. Os dados poderão permanecer apenas em um array JavaScript enquanto a página estiver aberta.

Ponto de partida: abaixo existe uma SPA completa de Cadastro de Alunos. Você pode executá-la dentro desta própria página e, em seguida, copiar todo o código-fonte para iniciar sua atividade.

3. Adapte a aplicação

1

Escolha o tema

Selecione um dos dez estudos de caso e altere títulos, textos, campos e informações exibidas.

2

Mantenha a ideia de SPA

A aplicação deve possuir uma tela inicial, uma tela de cadastro ou inserção, uma tela de listagem e uma tela Sobre ou equivalente, sem criar um novo HTML para cada tela.

3

Manipule o DOM

Use JavaScript para trocar o conteúdo principal da aplicação, responder aos cliques e atualizar a listagem.

4

Armazene em memória

Use um array JavaScript para guardar os dados durante a execução. Não é necessário banco de dados.

4. Organize os arquivos

O código fornecido está propositalmente em um único arquivo. Depois de entender e adaptar a aplicação, você deverá separar cada responsabilidade.

projeto-spa/ │ ├── index.html │ ├── css/ │ └── style.css │ └── js/ └── app.js

index.html

Deve ficar com a estrutura HTML. Remova o conteúdo das tags <style> e <script> e faça as referências aos arquivos externos.

css/style.css

Mova para este arquivo todo o CSS que estava dentro da tag <style>.

js/app.js

Mova para este arquivo todo o JavaScript que estava dentro da tag <script>.

Teste novamente

Depois da separação, abra o index.html e confirme que cadastro, navegação, listagem e exclusão continuam funcionando.

6. Requisitos mínimos






Escolher um dos 10 estudos de caso.


Adaptar o template para o tema escolhido.


Possuir uma tela inicial e pelo menos três outras telas ou áreas.


Navegar entre as telas sem recarregar a página.


Manipular o DOM utilizando JavaScript.


Possuir pelo menos um formulário.


Armazenar os dados temporariamente em um array.


Exibir dinamicamente os dados cadastrados.


Possuir pelo menos uma ação sobre os dados, como excluir, concluir, favoritar ou alterar status.


Separar corretamente HTML, CSS e JavaScript no final.







7. Entrega




Estrutura obrigatória


Entregue a pasta completa do projeto. A aplicação deverá iniciar pelo arquivo index.html e funcionar depois da separação dos arquivos.

css/style.css
js/app.js
