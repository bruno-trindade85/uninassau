Single Page Application — SPA na prática

Neste material, vamos compreender a ideia central de uma SPA usando um exemplo completo em HTML, CSS e JavaScript.

Meta da aula: entender como uma única página HTML pode mostrar conteúdos diferentes sem abrir outro arquivo HTML a cada clique.
Conceito

1. O que é uma SPA?

SPA significa Single Page Application, ou Aplicação de Página Única.

Em nosso exemplo didático, o navegador carrega uma página principal. Depois disso, o JavaScript altera somente a área de conteúdo que precisa mudar.

Usuário clica
→
JavaScript executa
→
Conteúdo muda

Ideia que você deve guardar

O documento principal continua aberto; o JavaScript troca o que aparece dentro de uma área da página.

Comando fundamental do exemplo

2. O que significa innerHTML?

innerHTML é uma propriedade do JavaScript usada para ler ou substituir o conteúdo HTML que está dentro de um elemento.

<main id="app"> <p>Conteúdo inicial</p> </main>

Se executarmos:

app.innerHTML = "<h2>Produtos</h2>";

O resultado visual equivale a:

<main id="app"> <h2>Produtos</h2> </main>
inner = interno, dentro. HTML = conteúdo HTML. Portanto, innerHTML pode ser entendido como “o HTML que está dentro do elemento”.
Por que isso é útil?

3. Principais vantagens percebidas neste exemplo

Navegação fluida

O usuário troca de conteúdo sem abrir um novo documento HTML.

Estrutura permanece

Cabeçalho, menu e rodapé podem continuar visíveis enquanto somente o conteúdo principal muda.

Controle pelo JavaScript

O JavaScript decide o que será exibido em resposta aos cliques do usuário.

Experiência mais dinâmica

A aplicação se comporta de forma mais próxima de um aplicativo do que de uma sequência de páginas independentes.

Entendendo o código

5. Principais linhas comentadas

1. onclick

<button onclick="mostrarProdutos()">

Quando o usuário clica, o navegador executa a função indicada.

2. getElementById

document.getElementById("app")

Procura no HTML o elemento cujo id é app.

3. innerHTML

app.innerHTML = `...`;

Troca o conteúdo que está dentro do elemento #app.

4. mostrarHome()

mostrarHome();

Executa a função quando a página abre, evitando que a área principal comece vazia.

Atividade prática

7. Sua tarefa: ampliar a Mini SPA

Você deverá partir do código completo apresentado neste material. Não crie uma aplicação do zero.

Parte 1 — crie um novo item de menu

Adicione ao menu um quarto botão. O nome fica a sua escolha. Exemplos: Sobre, Serviços, Equipe, Clientes, Cursos ou Galeria.

<button onclick="mostrarSobre()">Sobre</button>

Parte 2 — crie uma nova tela

Crie uma nova função JavaScript para o botão que você adicionou.

function mostrarSobre() { app.innerHTML = ` <h2>Sobre</h2> <p>Conteúdo criado pelo aluno.</p> `; }

Requisitos

Manter Home, Produtos e Contato funcionando.
Adicionar pelo menos um novo botão ao menu.
Criar uma nova função JavaScript correspondente ao novo botão.
Usar app.innerHTML para montar a nova tela.
Adicionar conteúdo próprio à nova tela.
Não criar outro arquivo HTML para a nova tela.

Desafio extra

Depois de criar a quarta opção, crie uma quinta opção de menu e uma quinta tela.

Perguntas para entregar junto com a atividade

1. O que o onclick faz?
2. Qual é a função de document.getElementById("app")?
3. O que o innerHTML modifica?
4. Por que a nova tela não precisa de um novo arquivo HTML?
Revisão

8. Resumo da aula

SPA significa Single Page Application.
Nosso exemplo utiliza uma única página HTML.
Os botões chamam funções JavaScript através de onclick.
getElementById("app") encontra a área que será modificada.
innerHTML substitui o conteúdo interno dessa área.
Adicionar uma nova “tela” significa criar um novo botão e uma nova função, sem criar outro documento HTML.
