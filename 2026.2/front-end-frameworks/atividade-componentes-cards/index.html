Construindo cards reutilizáveis

Crie um catálogo com três produtos usando HTML, CSS e JavaScript. Depois, adicione sozinho um quarto card.

1º momento

Copiar e executar

Crie a pasta, os três arquivos e coloque o código de cada etapa no lugar certo.

2º momento

Reutilizar o componente

Adicione um quarto produto sem duplicar a função que gera os cards.

Não é necessário instalar React ou Node.js. Basta um editor de texto e um navegador.
O que vamos aprender?

Engenharia de componentes e encapsulamento

Reutilização

Uma única função criarCard() constrói todos os produtos a partir de informações diferentes.

Separação de responsabilidades

HTML organiza a página; CSS cuida do visual; JavaScript constrói os cards e adiciona o comportamento.

Esta atividade apresenta os princípios de componentes com JavaScript puro. Componentes React serão vistos depois.

Antes de executar

Onde conseguir as imagens?

Pesquise e salve

Procure imagens de notebook, mouse e teclado na internet, preferencialmente com permissão de reutilização. Salve-as na pasta imagens.

Use os nomes notebook.jpg, mouse.jpg e teclado.jpg.

Confira os caminhos

imagens/notebook.jpg
imagens/mouse.jpg

Se baixar arquivos em formato PNG ou WebP, altere a extensão no JavaScript ou converta os arquivos.

Atenção: se a pasta ou o nome não corresponder, o card aparecerá, mas sua imagem ficará quebrada. Não é preciso criar imagens; basta procurá-las.

O que o HTML está fazendo?

Estrutura semântica

<header> define o cabeçalho, <main> o conteúdo principal, <section> a área de produtos e <footer> o rodapé.

Local dos cards

A div com id="lista-produtos" começa vazia; o JavaScript adicionará os produtos nela.

O HTML não precisa conter três cards escritos à mão. Eles serão gerados pelo JavaScript.

script.js

Cole este código no arquivo responsável pelos dados, pela criação de cards e pelo botão.

script.js
const produtos = [
  {
    nome: "Notebook",
    preco: 3500,
    imagem: "imagens/notebook.jpg"
  },
  {
    nome: "Mouse",
    preco: 120,
    imagem: "imagens/mouse.jpg"
  },
  {
    nome: "Teclado",
    preco: 250,
    imagem: "imagens/teclado.jpg"
  }
];

// Cria um card reutilizável para cada produto
function criarCard(produto) {
  const card = document.createElement("article");
  card.className = "card";

  const imagem = document.createElement("img");
  imagem.src = produto.imagem;
  imagem.alt = produto.nome;

  const nome = document.createElement("h3");
  nome.textContent = produto.nome;

  const preco = document.createElement("p");
  preco.className = "preco";
  preco.textContent = produto.preco.toLocaleString(
    "pt-BR",
    { style: "currency", currency: "BRL" }
  );

  const botao = document.createElement("button");
  botao.type = "button";
  botao.textContent = "Ver detalhes";

  botao.addEventListener("click", function() {
    alert("Produto: " + produto.nome);
  });

  card.append(imagem, nome, preco, botao);
  return card;
}

// Exibe cada card no catálogo
function mostrarProdutos() {
  const lista = document.getElementById(
    "lista-produtos"
  );

  produtos.forEach(function(produto) {
    const card = criarCard(produto);
    lista.appendChild(card);
  });
}

mostrarProdutos();
Salve o arquivo com o nome indicado, dentro da pasta catalogo-produtos.
Depois de copiar

Como surgem três cards com uma função?

Dados

Array produtos

Guarda nome, preço e imagem dos três produtos.

Componente

criarCard()

Recebe um produto e devolve um card HTML completo.

Exibição

mostrarProdutos()

Percorre o array e adiciona um card por produto à página.

Produto→criarCard()→Card na tela
A mesma função é executada para os três produtos: não há cópia do código de criação de card.
Passo 5

Execute no navegador

  1. Salve os três arquivos e as imagens na pasta correta.
  2. Abra index.html com dois cliques.
  3. Confira se aparecem os três produtos.
  4. Clique em Ver detalhes para exibir o nome.
  5. Se uma imagem não carregar, verifique nome, extensão e pasta.
Dica: se a página estiver desatualizada, recarregue-a com Ctrl + F5.

Agora crie o quarto produto

Escolha um produto diferente e acrescente um novo objeto ao array produtos, dentro do arquivo script.js.

Modelo a completar

Checklist do desafio

  • Defina o nome e o preço.
  • Encontre uma imagem e salve na pasta.
  • Adicione o objeto ao array com a vírgula correta.
  • Atualize a página: devem aparecer quatro cards.
Regra principal: não duplique a função criarCard(). Reutilize a função existente.
